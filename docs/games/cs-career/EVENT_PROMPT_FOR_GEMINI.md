# CS职业生涯模拟器 - 事件生成规则总结（供Gemini使用）

> 生成时间：2026-07-29  
> 用途：为Gemini生成高质量事件提示词提供规则约束与示例框架

---

## 游戏核心机制

- **四维数值系统**：能力(0-100)、关系(0-100)、清白(0-100)、名气(0-100)
- **职业生涯流程**：16岁起步 → 试训签约 → 赛季比赛 → 转会 → 退役（通常26岁巅峰，31岁后快速衰退）
- **决定性时刻**：每个休赛期1次重大选择，硬核模式每赛季额外0-2次突发事件
- **种子系统**：相同种子+相同选择 = 完全相同结果，事件概率必须透明且可复现

## 玩家核心反馈问题

### 问题1：事件太公式化，缺乏情感冲击

**当前问题**：
- 选择没有"加油"或"赎罪"的机会
- 缺少关键比赛中的决定性时刻
- 没有真正影响职业生涯轨迹的5050赌博式选择

**需要的事件类型**：
- **关键残局决策**：比赛最后一局，选择激进打法或保守防守，直接影响Major冠军归属
- **赎罪机会**：因早期失误（如重要比赛失误、队内冲突）导致后果，数个赛季后出现弥补机会
- **职业生涯分叉点**：如"接受海外强队替补"vs"留在国内当核心"，两条路线有完全不同的天花板

### 问题2：荣誉系统不合理

**当前问题**：
- 没有冠军、没有MVP，却能连续3年TOP1
- TOP1应该是人中龙凤，中国赛区进TOP20比登天还难

**荣誉生成规则**：

- **TOP20入选门槛**：
  - 必须至少6项计分赛事 + 1项大型以上赛事
  - 高级赛事表现权重 >> 基础数据
  - 若主要靠低级赛事刷数据，最高只能排第15名
  - 中国选手默认劣势，需要国际突破

- **冠军与MVP关联**：
  - Major冠军 + MVP → TOP5常客
  - 多个精英赛事冠军 → TOP10-15
  - 数据好但无冠军 → 最高TOP15-20
  - "无冕强者"是特殊结局称号

### 问题3：随机事件库太小

需要大幅扩展以下事件类别，且必须符合**取舍原则**（没有明显正确答案）

### 问题4：缺乏赌徒式的爽感反馈

**需要的高风险高回报事件**：
- 单次选择可能改变±15-25点数值
- 关键比赛时的战术决策直接影响冠军
- 长期后果（如"清白-20但关系+15"，3年后触发调查）

## 事件生成要求

### 核心原则

1. **每个选项必须有明确代价**：不存在"又要又要"的完美选项
2. **数值变化透明**：玩家能看到短期±值，长期后果可隐藏但需提示风险
3. **概率必须显示**：带随机性的选项必须标注完整概率分布，如"60%提升/40%失败"
4. **禁止必死选项**：所有选项都应有生存路径，只是代价不同
5. **长期后果延迟结算**：某些选择的真正代价在数个赛季后才触发

### 事件分类与生成需求

#### A. 关键比赛决策（新增，高优先级）

**场景**：Major决赛、区域冠军赛、保级生死战的关键残局或战术决策时刻

**示例框架**：

```
Major决赛第三图 14:15落后，你是最后一人，C4已安放。
听到脚步声接近包点，时间还剩25秒。

[激进反清] 
- 成功(40%)：完成残局，战队夺冠，个人Rating+0.3，名气+20，能力+5
- 失败(60%)：被击杀，失去冠军，名气-10，关系-8，"关键失误"标签

[保守拖延]
- 成功(70%)：拖到时间，赢得回合，但最终2:1输掉比赛
- 结果：亚军，关系+3，"稳健但不够决断"

[呼叫暂停求助队友建议]
- 队友给出激进建议，但执行责任仍在你
- 失败时关系额外-5（"为什么听他的"）
- 成功时关系+10（"信任队友"）
```

**要点**：
- 概率基于当前能力、心态、健康状态计算
- 失败不是游戏结束，而是留下"遗憾"标签，影响后续事件和结局称号
- 成功带来的回报要足够大，让玩家感受到"赌对了"的爽感

#### B. 赎罪与救赎线（新增）

**触发条件**：玩家曾经历重大失误（比赛失误、队内冲突、合同纠纷）

**示例框架**：

```
【事件】赛前遇到三年前那场Major决赛的对手
三年前那场1v2残局，你的失误让战队失去唯一一次Major冠军机会。
今天又是Major决赛，又是他们。

[在赛前采访中提及那场比赛]
- 名气+8，"复仇叙事"增加媒体关注
- 压力增加，本场比赛Rating期望-0.15
- 若本场获胜：名气额外+15，"救赎"正面标签
- 若本场失败：名气-12，"心魔未除"负面标签

[保持沉默，专注比赛]
- 压力正常，比赛表现不受影响
- 即使获胜也不会有"救赎"叙事加成

[私下找当年队友喝酒]
- 关系+10，心态+5
- 花费5万元
- 比赛表现小幅提升（健康-3）
```

## 生成事件时的检查清单

### 必须满足

- [ ] 每个选项有明确的数值代价（至少2项数值间取舍）
- [ ] 概率事件标注完整分布（成功%/失败%）
- [ ] 描述中包含玩家当前状态（如"你现在是替补""合同还剩1年"）
- [ ] 长期后果提示（"可能在未来触发调查""影响退役评价"）
- [ ] 数值变化幅度合理（常规±3-8，重大±10-25，极端可达±30）
- [ ] 符合中国CS职业圈现实（不出现不存在的赛事/战队）

### 避免事项

- [ ] 没有"又拿钱又涨能力又加关系"的万能选项
- [ ] 没有未提示的必死选项
- [ ] 没有"显然唯一正确"的选择（至少在某个维度有代价）
- [ ] 不要过度说教（"职业选手就应该..."）
- [ ] 不使用真实赛事品牌（用虚构映射：IEM→EIM，ESL→ESI，PGL→PJL等）

### 情感冲击要素（回应玩家反馈）

- [ ] **高风险高回报**：至少30%的选项是5050赌博式决策
- [ ] **关键时刻**：Major决赛、保级战、1vX残局等极端场景
- [ ] **长线叙事**：早期选择在多个赛季后产生后果或救赎机会
- [ ] **爽感峰值**：成功时给予超额奖励（如关键残局成功→名气+25+冠军+MVP）
- [ ] **遗憾刻画**：失败不是数值-5，而是"永久错过XX""留下心魔"等标签

## 中国赛区现实参照

- 初始生态：The MongolZ 亚洲第一、世界第9，TYLOO 亚洲第二、世界第87
- 其他中国队默认排在TYLOO之后
- 中国选手进入TOP20是极其稀有的成就
- 进入世界前5需要Major冠军+MVP等顶级荣誉
- 中国队进T1/Major机会少：通常从亚洲公开预选起步
- CNCS复兴线：若玩家触发特殊条件，可永久改善中国赛区生态
